DiFloT._interp_candidate — Method
_interp_candidate(T_l,T_u,r_l,r_u,F,max_iter,tol)

Construct the interpolant of w(T)=v(T)-F. In normalized coordinates q=(Tu-T)/L, its negative is P(q)=F-vu+guLq-(guL-(vu-vl))q^b. This avoids separately forming a and (T_u-T)^b. The projection guarantees an interior integer test point even if the numerical root is inaccurate.

DiFloT.solve_mccp — Method
solve_mccp(session, theta; tol=FLOW_TOL, force=false) -> MCCPResult

Evaluate the continuous value function at theta. For integer parameters, reconstruct the integer objective from a rounded, exactly feasible static flow. A nonoptimal solver status or invalid flow is an error, not evidence of network infeasibility. Calls count actual optimize! invocations.

A numerical LP optimum is not an independent exact optimality certificate.
